# Команды бота xyliganimbot

## Пользовательские команды

### /help

Показывает справку: описание бота, как использовать поиск, список команд и примеры.

- **Где:** в разрешённом чате (чат должен быть в `chats.allowed`).
- **Ответ:** текст со списком команд и примерами (в группе — упоминание бота или /search, в личке — /search).

### /search запрос

Поиск по базе знаний. Возвращает найденные разделы с цитатами.

- **Где:** в разрешённом чате; в личке — основной способ поиска.
- **Пример:** `/search как настроить VPN`
- Если после `/search` ничего не указано, бот пришлёт подсказку: «Используйте: /search ваш запрос».

**В группе** можно также написать запрос и упомянуть бота (например, `@xyliganim_bot настройка VPN`) — бот ответит результатами поиска.

**В личке** без команды бот подскажет: «Используйте: /search ваш запрос».

## Админские команды

Доступны только пользователям из списка `admins` в конфиге. В разрешённом чате команда вызывается как `/admin подкоманда`.

### /admin

Без подкоманды — бот ответит: «Команда /admin требует подкоманду» и списком: load_model, vectorize.

### /admin load_model

Загрузка embedding-модели из HuggingFace в папку `models/`. Выполняется один раз при настройке или при смене модели.

- Требуется интернет.
- Модель по умолчанию: `intfloat/multilingual-e5-small`.

### /admin vectorize

Векторизация контента из `data/knowledge.md` через загруженную модель и сохранение векторов в кэш (`data/knowledge_cache.json`). Нужно выполнять после обновления документа или первой настройки.

- Требуются: файл `data/knowledge.md` и модель в `models/`.
- После успешной векторизации контекст поиска обновляется без перезапуска бота.

---

## Доступ и белые списки

- **Чаты:** бот обрабатывает сообщения только в чатах из `chats.allowed`. В остальных чатах не отвечает (в логах — «Access denied»).
- **Админы:** команды `/admin` и подкоманды доступны только пользователям из `admins`. Остальным бот отвечает: «Команда доступна только администраторам.»

Импорт контента из Google Docs выполняется **отдельным скриптом** (`python testing/test_import_content.py`), не командой бота.
